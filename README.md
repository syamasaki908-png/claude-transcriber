# Claude文字起こし

スマホのブラウザで動く文字起こしアプリ（PWA）です。会話をその場で文字にし、ふだん使っている **Claudeアプリ** に渡して議事録・要約・整形・質問応答を行います。APIキーは不要です。

公開URL: https://syamasaki908-png.github.io/claude-transcriber/

## 仕組み

| 役割 | 担当 |
|---|---|
| 音声 → 文字（リアルタイム） | 端末ブラウザの音声認識（Android: Chrome / iPhone: Safari） |
| 議事録・要点・ToDo・整形・質問 | Claudeアプリ（指示文と文字起こしをコピー／共有して渡す） |
| 保存 | 端末内の IndexedDB（サーバーには送りません） |

※ Chrome の音声認識は音声を Google のサーバーに送って処理します。

## Claudeアプリとの連携

1. 記録を開き「Claude」タブで、頼むこと（議事録・要点まとめ・ToDo抽出・読みやすく整形・質問）を選ぶ。
2. 「コピーしてClaudeを開く」→ Claude の入力欄に貼り付けて送信。または「ファイルで送る」→ 共有先で Claude を選ぶ。
3. Claude の回答をコピーして「回答を保存」に貼り付けると、記録と一緒に保存・バックアップされる（「結果」タブ）。

長い記録の「整形」は、回答が途中で切れないよう約12,000文字ごとのパートに分けて送ります。

## 長時間録音と保存

- 確定した文は約1秒以内に端末へ自動保存されます。
- 設定した間隔（1/3/5/10分）でスナップショットを「バックアップ」として別に保存し、記録ごとに最新N件を残します。開始時・停止時・結果保存後にも保存します。
- 録音中にアプリが落ちたり再読み込みされたりしても、次に開いたとき「中断」として表示され、続きから録音できます。
- 録音中は画面が消えないようにします（Wake Lock）。アプリを切り替えると止まる場合があります。
- 音声も保存する設定にすると、10秒ごとに区切って保存します（1時間で約15〜30MB）。
- 「全データを書き出す」で JSON ファイルにまとめて保存でき、別の端末で復元できます。

## ローカルで試す

```bash
python -m http.server 8765 --directory transcriber
```
