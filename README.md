# Claude文字起こし

スマホのブラウザで動く文字起こしアプリ（PWA）です。会話をその場で文字にし、Claude で整形・議事録作成・質問応答を行います。

## 仕組み

| 役割 | 担当 |
|---|---|
| 音声 → 文字（リアルタイム） | 端末ブラウザの音声認識（Android: Chrome / iPhone: Safari） |
| 句読点・段落・話者分け、議事録、要約、Q&A | Claude API（設定画面でAPIキーを入力） |
| 保存 | 端末内の IndexedDB（サーバーには送りません） |

※ Claude は音声を直接受け取れないため、文字起こし自体は端末の音声認識で行います。Chrome の音声認識は音声を Google のサーバーに送って処理します。

## 長時間録音と保存

- 確定した文は約1秒以内に端末へ自動保存されます。
- 設定した間隔（1/3/5/10分）でスナップショットを「バックアップ」として別に保存し、記録ごとに最新N件を残します。開始時・停止時・整形後・要約後にも保存します。
- 録音中にアプリが落ちたり再読み込みされたりしても、次に開いたとき「中断」として表示され、続きから録音できます。
- 録音中は画面が消えないようにします（Wake Lock）。アプリを切り替えると止まる場合があります。
- 音声も保存する設定にすると、10秒ごとに区切って保存します（1時間で約15〜30MB）。
- 「全データを書き出す」で JSON ファイルにまとめて保存でき、別の端末で復元できます。

## 使い方

1. HTTPS のURLで公開し、スマホで開く（マイクは HTTPS でないと使えません）。
2. 「ホーム画面に追加」するとアプリのように起動できます。
3. 設定（歯車）で Claude APIキーを入力。
4. 「録音を開始」→「停止して保存」→ 記録を開いて「整形」「要約」「質問」。

## ローカルで試す

```bash
python -m http.server 8765 --directory transcriber
```

ブラウザで http://localhost:8765 を開きます。
